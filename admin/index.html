Визиты по дням

Один визит = одна загрузка страницы. Без cookies, поэтому повторные визиты одного человека считаются отдельно.

Откуда пришли

UTM-метки

Ставь ?utm_source=linkedin&utm_campaign=bio на ссылки в постах и шапках, и здесь будет видно, что работает.

Страны

Устройства и язык

До какого блока доходят

Доля визитов, которые увидели блок. Разница между соседними строками показывает, где уходят.

Где проводят время

Среднее время, пока блок занимает большую часть экрана (только видимая вкладка).

Глубина прокрутки

Сколько визитов дошли до каждой доли страницы.

Какие кейсы открывают

Заявки из чата

Бриф, который человек собрал в чате на сайте. Контактов в нём нет: человек отправляет сообщение тебе в Telegram сам. «Отправил» значит, что он нажал кнопку отправки.

Доступ к GitHub

Кейсы хранятся в репозитории сайта. Чтобы сохранять правки, нужен токен GitHub с доступом только к olzie/portfolio (Contents: Read and write). Он хранится только в этом браузере.
